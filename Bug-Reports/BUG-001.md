# BUG-001: Invalid Product IDs Cause Inconsistent Cart Badge Behaviour

| Field | Details |
|---|---|
| **Bug ID** | BUG-001 |
| **Title** | Invalid Product IDs Cause Inconsistent Cart Badge Behaviour |
| **Module** | Product Browsing / Shopping Cart |
| **Severity** | Medium |
| **Priority** | High |
| **Status** | Reproduced |
| Affected Accounts | standard_user, locked_out_user, problem_user, performance_glitch_user, error_user, visual_user |
| **Testing Type** | Negative / Edge Case |

## Environment

- **Application:** https://www.saucedemo.com/
- **Operating System:** Windows 11
- **Browser:** Google Chrome
- **Browser Version:** 156.0.8078.80
- **Device:** Desktop / PC

## Description

When accessing a product using an invalid product ID greater than `5`, the application displays an error message and an invalid price. However, clicking the Add to Cart button still increases the cart badge count even though the invalid product is not actually added to the shopping cart.

The same behaviour was observed with multiple product IDs greater than `5`, rather than being limited to a single invalid ID.

This results in an inconsistency between the cart badge count and the actual cart contents.

## Preconditions

- User is logged in using `standard_user`.
- User has access to the SauceDemo application.

## Steps to Reproduce

1. Open https://www.saucedemo.com/.
2. Log in using `standard_user` and password `secret_sauce`.
3. Navigate directly to a product URL using an ID greater than `5`, for example:

   `https://www.saucedemo.com/inventory-item.html?id=6`

4. Observe the product details page.
5. Verify that the page displays the invalid product message.
6. Click the **Add to Cart** button.
7. Observe the cart badge count.
8. Open the shopping cart.
9. Verify whether the invalid product is displayed.
10. Repeat the same steps using other product IDs greater than `5`.

## Expected Result

The application should validate product IDs and handle invalid IDs gracefully. Products that do not exist should not be addable to the cart, and the cart badge count should remain unchanged.

## Actual Result

- Product IDs greater than `5` display `ITEM NOT FOUND`.
- The product price appears as `$√-1`.
- Clicking Add to Cart increases the cart badge count.
- However, the invalid product does not appear in the shopping cart.
- The same behaviour was observed with multiple product IDs greater than `5`.

## Impact

The cart badge displays an incorrect item count, creating an inconsistency between the displayed cart quantity and the actual cart contents. This may confuse users about the products they have selected.
