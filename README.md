# Manual QA Testing for SauceDemo

This testing was done to find bugs in the SauceDemo website without using any automation tools, by inspecting the browser and testing the features manually.

This repo contains a test plan, which explains what I tested and how, along with a bug report documenting the bugs I found, with steps to reproduce and screenshots.

## Test details

- **Site URL:** https://www.saucedemo.com/
- **Usernames tested:** all except `locked_out_user`, because I couldn't access that account
- **OS:** Windows 11
- **Browser:** Google Chrome
- **Version:** 156.0.8078.80

## Contents

- `test-plan.pdf`: scope, types of testing, test cases and risk assessment
- `bug-report.pdf`: the bugs I found, with steps, expected and actual results, and screenshots
